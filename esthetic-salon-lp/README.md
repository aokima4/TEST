# エステサロン開業まるごとパック｜LP

エステサロン開業支援サービスのランディングページです。

## ファイル構成

```
esthetic-salon-lp/
├── index.html   … LP本体（HTML / CSS / JS すべて1ファイル）
├── assets/      … 画像を置くフォルダ（現在は空）
└── README.md    … このファイル
```

## 使い方

`index.html` をブラウザで開くだけで表示できます。
公開するときは、このフォルダごとサーバーにアップロードしてください。

## 本番公開前に差し替えが必要な箇所

| 場所 | 内容 |
|---|---|
| `<link rel="canonical">` / `og:url` / `og:image` | 実際のURLと、SNSシェア用画像（1200×630px） |
| `<link rel="icon">` | ブランドロゴのファビコン |
| 最終CTAのボタン `href="#"` | 問い合わせフォーム または LINE友だち追加のURL |
| 代表メッセージの「山田 花子」 | 実際の代表者名 |
| 運営会社セクションの数字 | 実績値（制作実績数など） |
| フッターのコピーライト | 実際の会社名 |
| 各画像（仮画像が入っています） | 下記「画像について」を参照 |

## 画像について

現在、すべての画像箇所に **仮画像（ブランドカラーで作成したイラスト）** が入っています。
そのままでも公開できる状態ですが、実写の写真に差し替えると訴求力がさらに高まります。

仮画像の保存場所：`assets/placeholder/`

| ファイル | 使用箇所 | 差し替える実写のイメージ |
|---|---|---|
| `hero-owner.svg` | ファーストビュー | 女性サロンオーナーがPCとスマホを使うシーン（横1600px以上） |
| `future-01-instagram.svg` | 導入後の未来 01 | スマホでサロンのInstagramを見る手元 |
| `future-02-line.svg` | 導入後の未来 02 | 公式LINEの画面を見るオーナー |
| `future-03-branding.svg` | 導入後の未来 03 | ロゴ入り名刺・メニュー表などのフラットレイ |
| `future-04-template.svg` | 導入後の未来 04 | PCでSNS投稿テンプレートを編集する女性 |
| `ceo-portrait.svg` | 代表メッセージ | 代表ポートレート（縦4:5） |
| `final-cta-salon.svg` | 最終CTA背景 | 広く明るいサロン空間（横2000px以上） |
| `ogp.svg` | SNSシェア画像 | 1200×630px のJPGまたはPNGで書き出して `assets/ogp.jpg` へ |

### 差し替え方法

`index.html` の該当する `<img>` の `src` を変えるだけです。

```html
<!-- 変更前 -->
<img src="assets/placeholder/hero-owner.svg" ... alt="...">
<!-- 変更後 -->
<img src="assets/hero-owner.jpg" ... alt="...">
```

`alt`（画像の説明文）は、写真の内容に合わせて書き換えてください。
目の不自由な方や検索エンジンが画像の内容を理解するために使われます。

### 写真を選ぶときの方向性

- 自然光の入る明るい空間
- アイボリー・ベージュ・白・木・大理石・ゴールド・グリーン
- 余白のある構図
- モデルは30〜40代の、清潔感と品のある女性
- 「施術を受ける人」より「サロンオーナーとして働く人」を多めに（目安7:3）
