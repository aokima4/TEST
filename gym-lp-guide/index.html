00 読むだけ / 5分

この手順書で、何ができあがるか

結論

できあがるのは、「無料カウンセリングの申し込み」を取るための1枚のWebページと、 そのページをChatGPTやClaudeなどのAIが引用できる状態にするための裏側の設定です。 作業は文章を書くだけ。コードは書きません。

いま、見込み客の探し方が変わりました。「駅名＋パーソナルジム」で検索して10件を見比べる人だけでなく、 AIに「この駅でおすすめのパーソナルジムは？」と聞いて、返ってきた3件だけを見る人が増えています。 このとき、AIは「答えに使える情報が書いてあるページ」しか候補に挙げません。この手順書は、その候補に入るための作り方です。

進め方は3つだけ

  1. 自分の店の情報を決める（工程01〜04）
    紙とペンでもできます。ここが一番大事で、一番時間がかかります。
  2. AIにデザインを作らせる（工程05）
    このページの中にある「プロンプト作成フォーム」に入力すると、貼り付ける文章が自動でできます。
  3. AIに仕上げをさせて、公開前に確認する（工程06〜07）
    決まった指示文をコピーして貼るだけです。
プロンプトとは：AIに出す「指示文」のことです。話し言葉で書いて大丈夫ですが、 指示が具体的なほど結果が良くなります。この手順書では、その指示文をこちらで用意してあります。
01 準備 / 20分

道具と材料をそろえる

結論

使う道具は2つだけ。材料（自店の情報）は7項目。 材料が揃っていないと工程05で必ず止まるので、ここで全部埋めてください。

使う道具は2つ

道具 1 / 見た目をつくる

Claude Design

「こういうページが欲しい」と文章で伝えると、Webページの見た目を作ってくれるサービスです。 Webサイト上で動くので、インストールは不要です。
claude.ai/design

道具 2 / 中身を仕上げる

Claude Code

できあがった見た目を、本物のWebページのファイルに仕上げてくれる道具です。 工程06で「AIに読ませる情報」を追加してもらうために使います。制作会社に依頼する場合は、 工程06の指示文をそのまま渡せば同じことができます。

Claude（クロード）とは：ChatGPTと同じ「対話型AI」の一種で、Anthropic社が提供しています。 文章を書くのが得意で、Webページのデザインやコードも作れます。無料でも試せますが、 ページ制作は処理が重いので有料プラン（月額20ドル前後）を推奨します。

そろえる材料 7項目

チェックを入れながら確認してください。空欄のまま先に進まないでください。

写真がなくても、ここで止まらないでください

撮影待ちでLP制作が半年止まる、というのがよくある失敗です。工程05のプロンプトには 「写真は未撮影なので配置場所だけ指定してください」と書いてあります。 枠だけ作って、後から写真を入れれば大丈夫です。

02 方針決め / 15分

勝負を決める2つの原則

結論

① 総額を書く。② トレーナーが誰かを書く。 この2点だけで、他のパーソナルジムとほぼ差がつきます。デザインの良し悪しより先に、ここを決めてください。

原則①　「月々9,800円〜」は、AIに無視されます

業界で非常に多いのが「月々9,800円〜」だけを載せたLPです。人間なら「まあ後で聞けばいいか」と思いますが、 AIは違います。「2ヶ月16回で総額いくら？」という質問に答えられないので、この店を候補から外します。 見込み客はAIに必ず「相場はいくら？」と聞くので、隠すほど不利になります。

これだと引用されない

月々9,800円〜
今なら入会金無料！

総額が計算できない。AIは「答えに使えない情報」として扱います。

これなら候補に入る

16回・2ヶ月
総額298,000円
（入会金込み・追加費用なし）

比較の質問が来るたびに、候補として挙がるようになります。

原則②　パーソナルは「誰に教わるか」を買う商売です

AIも同じ見方をします。実名・保有資格・指導実績・顔写真が載っているLPと、 「経験豊富なプロトレーナー」としか書いていないLPでは、扱いがまったく変わります。 後者は裏が取れないので引用されません。「この駅で、女性トレーナーがいるパーソナルジムは？」という質問に、 AIが自信を持って答えられるかどうかが分かれ目です。

書き方AIの扱い
経験豊富なプロトレーナーが指導検証できないため、引用されない誰のことか特定できない
山田太郎／NSCA-CPT保有／指導実績1,200名／写真ありそのまま引用される名前・資格・実績が事実として使える
AEO（エーイーオー）とは：Answer Engine Optimization の略で、 「AIの答えの中に自分の店を出すための対策」のことです。 これまでの検索順位対策（SEO）のAI版だと考えてください。この手順書は全体がAEO対策になっています。
03 書き出し / 15分

聞かれる質問を書き出す

結論

パーソナルジムで聞かれるのは、設備の話ではなく「高い買い物への不安」です。 下の9項目に、自分の店の答えを用意してください。これがそのままLPの「よくある質問」になります。

セルフ型ジム（24時間ジムなど）とは、聞かれ方がまったく違います。 月7,000円のジムと、総額30万円のジムでは、見込み客の心配ごとが別物だからです。

解約条件と返金規定は、必ず書いてください

「不利な情報だから隠したい」と思われるかもしれませんが、逆です。 高額商材で客が一番不安なのはそこなので、書いてある店が信頼されます。 AIも「解約条件が明記されている＝誠実な事業者」として扱う傾向があります。 ただし文面は、公開前に専門家の確認を（工程07）。

04 構成決め / 15分

ページの構成を決める

結論

一般的なジムのLPから、3か所を差し替えます。 設備自慢をやめて、トレーナーの紹介にページの一番いい場所を使ってください。

よくあるジムのLPパーソナルジムでは
設備・マシン一覧トレーナー紹介実名・資格・実績・顔写真を1人ずつ
月額料金表総額料金表回数 × 期間 × 総額の3点セット
1日の流れ卒業までの流れカウンセリング → 初回 → 中間 → 卒業後フォロー

セクションはこの順番で並べます

  1. ヒーロー（一番上の大きな部分）
    見出しの下に必ず1文の説明を置きます。「〇〇は、〇〇駅 徒歩5分のパーソナルジムです。16回・2ヶ月で総額29.8万円、追加費用はありません」。AIはこの1文をそのまま引用します。
  2. 迷っている人への共感
    3つの不安に短く答える。
  3. トレーナー紹介
    ここをページで一番印象に残る部分にします。
  4. 料金表
    回数・期間・総額を並べ、追加費用の有無を明記。
  5. 卒業までの流れ
  6. よくある質問（12問）
    見出しは質問文そのまま。解約条件・返金規定・食事指導の内容を必ず含める。
  7. アクセス・営業時間
    地図の場所を確保しておく。
  8. 店舗情報
    店名・住所・電話番号・運営会社。
なぜ「見出しの下に1文の説明」なのか： AIはページを読むとき、キャッチコピーではなく「事実が書かれた文」を探します。 「理想の身体へ。」だけでは何の情報にもなりません。1文に、店名・場所・料金を入れてください。
05 制作 / 40分

デザインを作らせる

結論

下のフォームに自店の情報を入れると、貼り付けるだけの指示文が自動でできます。 それを claude.ai/design で 「プロトタイプ」を選んで貼り付ければ、数分でLPの見た目ができあがります。

操作の手順

  1. claude.ai/design を開き、ログインします。
  2. 作るものを選ぶ画面で 「プロトタイプ」 を選びます。（試作品、という意味です。まず形を作る、と考えてください）
  3. 下のフォームを埋めて、「指示文をコピー」ボタンを押します。
  4. Claudeの入力欄に貼り付けて送信。数分待つと、ページが表示されます。
  5. 気に入らない部分があれば、そのまま日本語で直しを頼みます（下に言い方の例があります）。
入力フォーム

あなたの店の情報を入れてください

Person型ここが最重要
トレーナー1人ずつを「人物」として登録します。名前・肩書・保有資格をセットで書くので、「この駅で女性トレーナーがいるジムは？」という質問に、AIが自信を持って答えられるようになります。工程02の②がここで効きます。

      
FAQPage

サイトの目次。検索エンジンやAIが、ページを見落とさないようにするためのものです。

      07
      確認 / 30分
    

    
公開前の法務チェック


    

      
結論

      
公開ボタンを押す前に、4点だけ確認してください。
      パーソナルジムは、LPの文言そのものが実際に紛争の材料になっている業種です。
      特に「今日だけ割引」と「月々〇〇円〜」は使わないのが安全です。

    


    
以下は法律の専門家による助言ではありません。最終判断は必ず弁護士等にご確認ください。
    ここでは「実際に争点になった論点」をお伝えします。


    

      
      
      
      
    


    

      
言い換えの具体例

      

      「今なら入会金無料！本日限り」　→　「入会金は0円です（常時）。総額298,000円のほかに費用はかかりません」

      「月々9,800円〜」　→　「16回・2ヶ月　総額298,000円（分割は月々〇〇円から、手数料〇%）」

      「−10kg達成！」　→　「運動経験のない方の3ヶ月継続率92%（2025年実績・対象〇名）」

      付録
      つまずいたとき
    

    
よくあるつまずき


    
AIが出してきたデザインが、思っていたものと全然違う
      
やり直しではなく、そのまま直しを頼んでください。「作り直して」と言うと、また違うものが出てきます。
      「トレーナー紹介をもっと大きく」「色を落ち着かせて」のように、不満のある場所と、どうしてほしいかを1つずつ伝えるのが早道です。

    


    
総額を出すと高く見えて、問い合わせが減りませんか
      
減るのは「総額を知ったら来なかった人」です。その人は、体験に来ても契約しません。
      総額を書くと、問い合わせ数は減っても、成約率と現場の負担が改善することが多いです。
      加えて、AIの比較質問で候補に入るようになるため、中期では露出が増えます。

    


    
トレーナーの実名や顔写真を出したくない（退職リスクが心配）
      
気持ちは分かりますが、パーソナルジムでここを伏せるのは、商品を隠して売るのと同じです。
      どうしても難しい場合は、最低でも「保有資格・指導年数・指導実績人数」だけは実数で出してください。
      退職時は、その人のセクションを差し替えれば済みます（工程06の Person 型は1人ずつ独立しています）。

    


    
写真がまだ1枚もありません
      
進めて大丈夫です。工程05の指示文に「写真は未撮影なので配置場所だけ指定してください」と入っています。
      枠だけ作って公開し、撮影後に差し替えてください。公開が遅れることのほうが、はるかに損失が大きいです。

    


    
制作会社に頼んでいます。この手順書は使えますか
      
使えます。工程01〜04（材料と構成）をそのまま発注書として渡し、
      工程06の指示文を「これも実装してください」と添えてください。
      構造化データやllms.txtは、対応していない制作会社もあるので、着手前に確認してください。

    


    
作ったあと、何を見れば効果が分かりますか
      
3つだけ見てください。①カウンセリング申込数　②申込〜来店率　③「どこで知りましたか」の回答。
      ③に「AIに聞いた」「ChatGPTで見た」が出始めたら、この手順書の狙いが効いています。
      公開から2〜3ヶ月は、AIに読み込まれるまでの時間がかかります。

    


    
他店に真似されませんか
      
真似できるのは書式だけです。総額とトレーナーの実績は、その店の中身そのものなので、
      真似した時点で相手も同じ土俵に立つことになります。むしろ、ほとんどの店は総額の公開に踏み切れません。
      そこが当面の差になります。
