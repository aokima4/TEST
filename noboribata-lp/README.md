# のぼり旗 外注パートナー ／ AEO対策LP

## 結論：このフォルダの中身と、やることは3つだけです

1. **`index.html` の黄色いマーカー部分を、本当の情報に書き換える**（下の「要確認リスト」参照）
2. **同じ数字を、ファイル末尾の「構造化データ」と `llms.txt` にも反映する**
3. **4つのファイルをサーバーのトップ階層にアップロードする**

これで公開できます。デザインもスマホ対応も済んでいます。

## そもそもAEOとは？（1分で）

**AEO（エーイーオー）= Answer Engine Optimization ／ 回答エンジン最適化**

これまでのSEOは「Googleの検索結果で上に出る」ための対策でした。
AEOは「**ChatGPT・Claude・Perplexity・GoogleのAI概要が答えるときに、自社が名指しで引用される**」ための対策です。

いま、お客さまは「のぼり 量産 外注」と10件のリンクを見比べるのではなく、
AIに「のぼり旗を1,000枚外注したい。どこがいい？」と聞いて、**AIが挙げた2〜3社にだけ**問い合わせます。

**AIに引用されるサイトの条件は、実はシンプルです。**

| AIが好むもの | 競合サイトの実情 |
|---|---|
| 質問の形の見出しと、その直後の明快な答え | 「お客様に寄り添った…」という抽象的な文章 |
| 具体的な数字（単価・日数・枚数） | 「お気軽にお問い合わせください」で数字なし |
| 表（テーブル）で整理された条件 | 画像に文字が入っていてAIが読めない |
| 機械向けの説明書き（構造化データ） | 未設置 |

**競合がAEO対策していない今が、一番有利です。**

## このLPで実際にやったAEO対策（12項目）

### 1. 結論を必ず先に書いた
ページ最上部に「先に結論」ボックスを置き、各見出しの直後にも赤い線の入った「答え」の段落を入れました。
AIはこの部分をそのまま引用します。

### 2. 見出しを「質問文」にした
「料金について」ではなく「**Q. のぼり旗の量産を外注すると、1枚いくらですか？**」。
人が検索で打ち込む言葉・AIに聞く言葉と、見出しを一致させています。

### 3. 具体的な数字を入れた
「安い」ではなく「1,000枚で1枚350円」。AIは数字がないページを引用できません。

### 4. 条件を全部「表」にした
料金表・納期表・他社比較表・生地比較表。AIは表を非常に正確に読み取ります。

### 5. 構造化データ（JSON-LD）を8種類設置した
ページの一番下にある機械向けの説明書きです。人には見えません。設置したのは以下です。

- `Organization`（会社情報）／`WebSite`／`WebPage`
- `Service` + `OfferCatalog`（サービス内容と枚数別価格）
- `FAQPage`（よくある質問16問）← **AEOで最も効きます**
- `HowTo`（発注の5ステップ）
- `BreadcrumbList`（ページの階層）
- `DefinedTermSet`（用語集）← AIが辞書として引用します

### 6. FAQを16問に増やした
「最低ロットは？」「掛け取引できる？」「白ラベル出荷は？」など、
**問い合わせないと分からなかったこと**を全部先に書きました。これが最大の差別化です。

### 7. 用語集を作った
「テトロンポンジ」「チチ」「昇華転写」など13語を解説。
AIは用語の説明を探しており、**用語解説ページは非常に引用されやすい**です。
「のぼり チチとは」のような検索からの流入も見込めます。

### 8. `llms.txt` を設置した
AI専用の要点まとめファイルです。AIが最短で内容を理解できます。
まだ設置している競合はほぼいません。

### 9. `robots.txt` でAIクローラーを明示的に許可した
GPTBot（ChatGPT）、ClaudeBot、PerplexityBot、Google-Extended など20種類を名指しで許可。
**何も書いていないと「拒否」と判断するAIもある**ため、明示が重要です。

### 10. E-E-A-T（信頼性）を強化した
会社概要・生産設備・生産能力・実績・最終更新日を明記。
AIは「誰が言っているのか分からない情報」を引用しません。

### 11. 画像ではなく文字で書いた
料金や条件を画像にすると、AIは1文字も読めません。全部HTMLの文字にしています。

### 12. 表示速度を極限まで速くした
外部の読み込みファイルゼロ、JavaScriptゼロ、画像ゼロ。約70KBの1ファイルのみです。

## 公開後にやること（重要度順）

1. **Google Search Console にサイトを登録**し、`sitemap.xml` を送信する（無料）
2. **構造化データのテスト**：<https://search.google.com/test/rich-results> に自社URLを入れて、
   FAQ・HowTo・Service がエラーなく認識されるか確認する
3. **実際にAIに聞いてみる**：ChatGPTやPerplexityで「のぼり旗 1000枚 外注 おすすめ」と検索し、
   自社が出てくるか、1〜2か月おきに確認する
4. **FAQを増やし続ける**：お客さまから電話で聞かれた質問を、その都度FAQに追加する。
   これがAEOで最も効く継続施策です（月2〜3問の追加を推奨）
5. **更新日を必ず直す**：内容を直したら `2026年9月8日` の表記と、
   構造化データの `"dateModified"` を更新する。AIは新しい情報を優先します
