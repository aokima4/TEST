## そもそもAEOとは？（1分で）

**AEO（エーイーオー）= Answer Engine Optimization ／ 回答エンジン最適化**

これまでのSEOは「Googleの検索結果で上に出る」ための対策でした。
AEOは「**ChatGPT・Claude・Perplexity・GoogleのAI概要が答えるときに、自社が名指しで引用される**」ための対策です。

いま、お客さまは「のぼり 量産 外注」と10件のリンクを見比べるのではなく、
AIに「のぼり旗を1,000枚外注したい。どこがいい？」と聞いて、**AIが挙げた2〜3社にだけ**問い合わせます。

例えるなら、これまでは「店の前で呼び込みをする」商売でした。
AEOは「AIという案内人に、店のメニューと値段を先に渡しておく」対策です。

| AIが好むもの | 競合サイトの実情 |
|---|---|
| 質問の形の見出しと、その直後の明快な答え | 「お客様に寄り添った…」という抽象的な文章 |
| 具体的な数字（単価・日数・枚数） | 「お気軽にお問い合わせください」で数字なし |
| 表（テーブル）で整理された条件 | 画像に文字が入っていてAIが読めない |
| 機械向けの説明書き（構造化データ） | 未設置 |

## このLPで実際にやったAEO対策（12項目）

### 1. 結論を必ず先に書いた
ページ最上部に「先に結論」ボックスを置き、各見出しの直後にも赤い線の入った「答え」の段落を入れました。AIはこの部分をそのまま引用します。

### 2. 見出しを「質問文」にした
「料金について」ではなく「**Q. のぼり旗の量産を外注すると、1枚いくらですか？**」。
人が検索で打ち込む言葉・AIに聞く言葉と、見出しを一致させています。

### 3. 具体的な数字を入れた
「安い」ではなく「1,000枚で1枚350円」。AIは数字がないページを引用できません。

### 4. 条件を全部「表」にした
料金表・納期表・他社比較表・生地比較表など7つ。AIは表を非常に正確に読み取ります。

### 5. 構造化データ（JSON-LD）を8種類設置した
ページの一番下にある、人には見えない機械向けの説明書きです。

- `Organization`（会社情報）／`WebSite`／`WebPage`
- `Service` + `OfferCatalog`（枚数別価格を6段階すべて登録）
- `FAQPage`（よくある質問16問）← **AEOで最も効きます**
- `HowTo`（発注の5ステップ）／`BreadcrumbList`
- `DefinedTermSet`（用語集）← AIが辞書として引用します

### 6. FAQを16問に増やした
「最低ロットは？」「掛け取引できる？」「白ラベル出荷は？」など、
**問い合わせないと分からなかったこと**を全部先に書きました。これが最大の差別化です。

### 7. 用語集を13語作った
「テトロンポンジ」「チチ」「昇華転写」など。AIは用語の説明を探しており、
**用語解説は非常に引用されやすい**です。「のぼり チチとは」等からの流入も見込めます。

### 8. `llms.txt` を設置した
AI専用の要点まとめファイル。まだ設置している競合はほぼいません。

### 9. `robots.txt` でAIクローラーを明示的に許可した
GPTBot（ChatGPT）、ClaudeBot、PerplexityBot、Google-Extended など20種類を名指しで許可。
**何も書いていないと「拒否」と判断するAIもある**ため、明示が重要です。

### 10. E-E-A-T（信頼性）を強化した
会社概要・生産設備・生産能力・実績・最終更新日を明記。
AIは「誰が言っているのか分からない情報」を引用しません。

### 11. 画像ではなく文字で書いた
料金や条件を画像にすると、AIは1文字も読めません。全部HTMLの文字にしています。

### 12. 表示速度を極限まで速くした
外部の読み込みファイルゼロ、画像ゼロ。約77KBの1ファイルのみです。
JavaScriptは「お問い合わせボタンでメールを作る」数十行だけで、本文はすべて静的な文字です
（AIは JavaScript を実行せずにページを読むため、ここが重要です）。

### ⚠️ この方式の弱点（検証段階では問題ありませんが、把握しておいてください）

| 弱点 | 内容 |
|---|---|
| メールソフト未設定だと送れない | スマホのGmailアプリ等が設定済みなら開きます。未設定の人は送信できません |
| 届いたか確認できない | 送信は閲覧者のメールソフトが行うため、こちらでは記録が残りません |
| 迷惑メールが増える | ページに書いたメールアドレスは、業者の自動プログラムに収集されます |

**本格運用に移すときは、フォーム送信サービス（formrun、Googleフォーム等）への切り替えをおすすめします。**
月額無料〜数千円で、「取りこぼしゼロ」「送信ログが残る」「迷惑メール対策込み」になります。
切り替えたい場合は、`index.html` の `<form ... action="mailto:...">` の部分を差し替えるだけです。

### 受信できるようにする方法（個人アドレスを載せずに）

**大前提：ページに書いたメールアドレスは、必ず第三者に見られます。**
ホームページの「ソースを表示」で誰でも読めますし、迷惑メール業者の自動プログラムが
毎日巡回して収集しています。**個人のメールアドレスは絶対に書かないでください。**

個人アドレスを一切載せずに問い合わせを受け取る方法は、次の2つです。

#### 方法A：ドメインのメールアドレスを作り、個人アドレスへ自動転送する（推奨）

1. ドメインを管理しているサービス（お名前.com、エックスサーバー等）の管理画面で、
   `info@noboribata-gaityuu-partner.com` のようなアドレスを作る
2. そのアドレスに届いたメールを、普段使っている個人のメールアドレスへ**自動転送**する設定にする

これで、**ページに載るのは会社のアドレスだけ**、実際の受信は普段のメールソフト、という形になります。
多くのレンタルサーバーで無料の標準機能です。ホームページ制作会社に頼んでいる場合は
「メール転送の設定をしてほしい」と伝えれば5分で終わります。

#### 方法B：フォーム送信サービスを使う（迷惑メール対策込み）

formrun、Googleフォーム、HubSpotなどの無料サービスを使うと、
**送信先アドレスはサービス側に保管され、ページには一切出ません。**

- 迷惑メール（自動プログラムからの大量送信）を自動で弾いてくれる
- 「誰がいつ送ったか」の記録が残るので、取りこぼしがない
- 月額無料〜数千円

`index.html` の `<form ... action="mailto:...">` の部分を、サービスが発行するURLに
差し替えるだけで切り替わります。ご希望があればお手伝いします。

## AEOの効果を、どう測るか

### 手順1：公開直後（初日）にやること

1. 4ファイルをサーバーにアップロード
2. **Google Search Console** に登録し、`sitemap.xml` を送信（無料）
3. **URL検査 → インデックス登録をリクエスト**（これをしないと数週間放置されます）
4. **構造化データのテスト**
   <https://search.google.com/test/rich-results> にURLを入れ、
   FAQ・HowTo・Service がエラーなく認識されるか確認

### 手順2：「公開前の状態」を記録しておく

**これが一番大事です。** 比較対象がないと、効いたかどうか分かりません。
公開前に、以下の質問をChatGPT・Perplexity・GoogleのAI概要に投げて、
**回答をスクショで保存**してください。

- 「のぼり旗を1000枚、外注で作りたい。おすすめの会社は？」
- 「のぼり旗の量産を外注すると1枚いくら？」
- 「のぼり旗 OEM 白ラベルで納品してくれる会社」
- 「販促会社がのぼり旗を外注する先の選び方」
- 「のぼり旗のテトロンポンジとトロマットの違いは？」

### 手順3：1・2・3か月後に同じ質問をする

同じ5つの質問を投げ直し、**自社が登場するか／何番目か／どの記述が引用されたか**を記録します。

| 見るポイント | 効いているサイン |
|---|---|
| 回答に自社名が出るか | 出れば成功。まず用語系（テトロンポンジ等）から引用され始めます |
| 出典リンクに載るか | Perplexityは出典を明示するので判定しやすいです |
| 引用された文章 | 「1,000枚で350円」など、**表の数字がそのまま引用**されていれば理想的 |
| Search Console の表示回数 | 質問形のキーワードでの表示回数が伸びていれば効いています |

### 効果が出るまでの目安

| 時期 | 起きること |
|---|---|
| 〜2週間 | Googleがインデックス。構造化データが認識される |
| 1〜2か月 | Perplexityなど、Web検索を毎回するAIが引用し始める |
| 2〜4か月 | GoogleのAI概要、ChatGPTの検索機能に反映され始める |
| 4か月〜 | 質問形キーワードでの流入が安定して増える |

**注意：** AEOは即効性のある施策ではありません。最低3か月は観測してください。
また、この検証は「仮の会社情報」で行うため、**実際の受注にはつながりません**。
効果が確認できた時点で、実際の情報に差し替えて本番運用に移すのがおすすめです。

### さらに効かせたい場合（効果を確認したあとで）

1. **FAQを増やし続ける** ← 最も費用対効果が高い施策です
   お客さまから電話で聞かれた質問を、その都度FAQに追加する。月2〜3問が目安
2. **用語集を増やす**
   「のぼり ○○とは」で検索される言葉を拾って追加。AIの辞書として引用されます
3. **更新日を必ず直す**
   内容を直したら本文の日付と、構造化データの `"dateModified"` を更新。
   AIは新しい情報を優先します
4. **記事ページを足す**
   「のぼり旗の耐用年数の実測」など、数字の入った独自データがあると強いです
