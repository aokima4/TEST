# のぼり旗の量産・外注パートナー ／ 株式会社後藤染工 — AEO対応ランディングページ

このフォルダは、**株式会社後藤染工**（愛知県春日井市／布製広告物の製作）の
BtoB向けサービスページ「のぼり旗の量産・外注パートナー」を、
**AEO（Answer Engine Optimization＝AIの回答に引用されるための対策）**済みで作り直したものです。

## 掲載内容について

ページに書かれている情報は、次の2つのサイトに実際に掲載されている内容だけで構成しています。
**架空の情報・推測で補った数字は一切含めていません。**

- https://www.noboribata-gaityuu-partner.com/ （価格表・選ばれている理由・事例紹介・ご注文の流れ・よくある質問・会社概要）
- https://www.gotosenko.co.jp/ （会社情報・取り扱い製品／印刷メディア・連絡先）

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | ページ本体（編集するのはこれ1つだけです） |
| `robots.txt` | ChatGPT・Claude・Perplexity など20種類のAIクローラーに「読んでよい」と許可する設定 |
| `sitemap.xml` | 検索エンジンに場所を伝えるファイル |
| `llms.txt` | AI向けの要約版。ページの要点をテキストだけでまとめたもの |
| `googled4a0ce84d6dc4e50.html` | Google Search Console の所有権確認ファイル（消さないでください） |
| `build-deploy.py` | 公開用ファイルを書き出すスクリプト |
| `dist/` | 公開用に書き出された完成ファイル一式。Vercelはこのフォルダを自動で公開します |

## 公開用ファイルの作り方

```
python3 build-deploy.py <公開先のURL> dist
```

例（検証用のVercel URLに出す場合）:

```
python3 build-deploy.py https://nobori-aeo.vercel.app dist
```

本番ドメインで公開する場合は:

```
python3 build-deploy.py https://www.noboribata-gaityuu-partner.com dist
```

このスクリプトは、ページの中に書かれているURL（canonical・sitemap・構造化データ）を
指定した公開先に置き換え、編集者向けのコメントを取り除いて `dist/` に書き出します。
URLがずれていると検索エンジンが「本物は別の場所にある」と判断してしまうため、
**必ずこのスクリプト経由で公開用ファイルを作ってください。**

`dist/` を手作業で一部だけ差し替えると、残りのファイルが消えてしまうことがあります。
必ず5ファイルすべてが揃っていることを確認してください。

## AEOとして入れている仕掛け

1. **見出しを質問の形にして、すぐ下に答えを1文で置く**
   （例：「Q. のぼり旗を外注すると1枚あたりいくらですか？」→「450mm×1,500mmで100枚なら＠259円〜です」）
   AIは「質問と答えのセット」を見つけると引用しやすくなります。
2. **具体的な数字を本文のテキストとして書く** — 画像の中の文字はAIが読めません。
3. **価格をHTMLの表（`<table>`）で書く** — 表はAIが構造を理解しやすい形式です。
4. **構造化データ（JSON-LD）** — 会社情報・サービス・価格・注文手順・よくある質問を、
   機械が読む用のデータとしてページ末尾に埋め込んでいます。
5. **`llms.txt`** — AI向けの要約ファイル。ページの要点をテキストだけでまとめています。
6. **`robots.txt` でAIクローラーを明示的に許可** — 何も書かないと「拒否」と判断するAIがあるためです。
