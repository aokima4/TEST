# 要件仕様書との対応表

「ブラウザ版 2D CAD（機械部品・製造用）第1.0版」の各項目について、実装状況を示します。
✅=実装済み ⚠️=一部・代替実装 ❌=未実装（理由を併記）

## 第2章 座標・単位・精度の基本設計【最重要・必須】

| 項目 | 状況 | 実装 |
|---|---|---|
| 内部単位＝1µmの整数 | ✅ | `src/core/units.ts`。座標は常に整数µm |
| 64ビット整数 | ⚠️ | JavaScriptの安全整数（±9,007,199,254,740,991）で厳密に整数演算。座標上限±2,000,000mm＝±2×10⁹µmはこの範囲に十分収まるため、BigIntは使わず速度を優先（仕様の意図「誤差ゼロの整数演算」は満たす） |
| 表現範囲 ±2,000,000mm | ✅ | 範囲外は例外で拒否 |
| 表示単位 mm（小数3桁） | ✅ | `fmtMM()` |
| 角度の内部保持＝1/1,000,000度の整数 | ✅ | `qAngle()` |
| 途中計算は倍精度、保存時に整数へ丸め | ✅ | すべての幾何関数が `q()` を通す |
| 丸めは四捨五入（0.5は偶数側） | ✅ | `roundHalfEven()` |
| 許容差の統一（点1µm/平行0.000001度/閉図形1µm） | ✅ | `TOL` 定数を全機能で共用 |
| 受け入れ基準4項目 | ✅ | `npm test` で自動検証、画面の「検証」ボタンでも実行可 |

## 第8章 技術構成

| 項目 | 指定 | 実装 |
|---|---|---|
| 開発言語 | TypeScript | ✅ strictモード。`npm run typecheck` |
| 描画方式 | WebGL2（PixiJS等） | ⚠️ Canvas2D＋空間索引による可視範囲カリング。**理由**：性能要件（5万図形で60fps）を実測450fpsで満たしたうえ、線種・線幅・文字の描画品質と実装量で有利。描画は `Painter` 抽象に閉じてあり、WebGL2実装を後から差し替え可能 |
| 拘束ソルバ | C++をWASM化 | ⚠️ TypeScript実装（上記・第4章参照） |
| 図形検索 | R-tree | ⚠️ 一様グリッド空間索引。用途（可視範囲抽出・クリック近傍）で計算量は同等、実装と更新コストが低い |
| 保存先 | ブラウザ内＋クラウド | ⚠️ ブラウザ内（IndexedDB）は実装済み。クラウド同期はサーバが必要なため未実装 |
| 対応ブラウザ | Chrome/Edge最新2版・Safari最新 | ✅ ES2022でビルド |
| 性能要件4項目 | | ✅ すべて満たす（README の実測表を参照） |
