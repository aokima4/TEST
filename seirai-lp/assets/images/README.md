# 写真の入れ方（3ファイル置くだけです）

このフォルダに、下の名前で写真を保存してください。
名前さえ合っていれば、LPは自動で写真に切り替わります（置くまでは仮の枠が表示されます）。

| ファイル名 | 使う写真 | 推奨サイズ | 使われている場所 |
|---|---|---|---|
| `founders-hero.jpg` | 代表2名が並んだ写真（ブランドボードのメインビジュアル） | 横1600px以上 | ファーストビュー／代表紹介／最後のメッセージ背景 |
| `founder-aoki.jpg` | 青木 真弓さんの写真（黒ジャケットのもの） | 縦900px以上 | 09 代表紹介 |
| `founder-tanaka.jpg` | 田中 結子さんの写真（白トップスのもの） | 縦900px以上 | 09 代表紹介 |
| `ogp.jpg`（任意） | SNSシェア時に出る画像 | 1200×630px | SNSシェア用 |

## ポイント
- 拡張子は `.jpg` にそろえてください（`.png` の場合は `index.html` 内のファイル名も合わせて変更が必要です）。
- 1枚あたり 500KB 以下に圧縮すると、スマホでの表示が速くなります。
- 顔が切れないよう、人物が中央〜やや上に来る写真を選ぶときれいに収まります。
