## 差し替えるとき

同じファイル名で上書き保存すれば、そのまま反映されます。HTMLを編集する必要はありません。

推奨サイズの目安：
- 代表2名の写真：横1100px以上
- 個人写真：縦900px以上（縦長・3:4に近い比率がきれいに収まります）
- 1枚あたり300KB以下に圧縮すると、スマホでの表示が速くなります

## 補足

`founder-tanaka.jpg` は元データが 371×395 と小さめのため、大きな画面では
やや粗く見える場合があります。より大きい元データがあれば差し替えをおすすめします。
